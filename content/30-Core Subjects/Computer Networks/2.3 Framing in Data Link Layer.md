# Framing in [Data Link Layer](2.%20Data%20Link%20Layer.md)

Character stuffing and bit stuffing are techniques used in computer networks to ensure that data is transmitted accurately and to prevent misinterpretation of control characters or sequences. Here’s a simple explanation of each:

### Character Stuffing

**What It Is:**
Character stuffing is a method used to insert additional characters into the data stream to differentiate between actual data and control information (like start and end markers).

![](00-Attachments/2.3 Framing in Data Link Layer-1.png)

**How It Works:**

- In character stuffing, special characters (often called "escape" characters) are added before a control character that might appear in the actual data.
- For example, if the control character for the end of a message is `#`, and the actual data contains `#`, an escape character (let’s say `ESC`) is inserted before each `#` in the data.
- So, if the original data is `Hello # World`, it is sent as `Hello ESC # World` to indicate that the `#` is part of the data and not the end of the message.

**Use Case:**
This technique is often used in protocols like PPP (Point-to-Point Protocol).

### Bit Stuffing

**What It Is:**
Bit stuffing is a technique where extra bits are added to a binary data stream to prevent certain bit patterns from being misinterpreted as control information.

![](00-Attachments/2.3 Framing in Data Link Layer.png)

**How It Works:**

- In bit stuffing, if a certain sequence of bits (for example, `11111`) appears in the data, an additional `0` bit is inserted after the sequence.
- For instance, if the original data is `1111110`, it is sent as `111110 0` to indicate that the sequence of five `1`s is part of the data and not a signal to do something special.

**Use Case:**
Bit stuffing is commonly used in protocols like HDLC (High-Level Data Link Control).

### Summary

- **Character Stuffing:** Adds special escape characters before control characters to differentiate between control and data.
- **Bit Stuffing:** Inserts additional bits to break up specific patterns in the data stream to avoid misinterpretation.

Both techniques help maintain the integrity of data during transmission by ensuring that the receiving end can correctly identify the boundaries of the data and distinguish it from control information.
