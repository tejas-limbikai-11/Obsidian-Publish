# Computer Network Protocols: OSI Model

The OSI (Open Systems Interconnection) model is a conceptual framework used to understand how different network protocols interact and work together in a layered architecture. It consists of seven layers, each responsible for specific functions in data communication. The OSI model helps standardize networking protocols, allowing different systems to communicate with each other efficiently.

## 7 Layers of the OSI Model:

![700](00-Attachments/osi-model.png)

1. [Physical Layer](1.%20Physical%20Layer.md) (Layer 1):
   - Responsible for the transmission and reception of raw bitstreams over a physical medium.
   - Examples: Ethernet cables, hubs, switches.

2. [Data Link Layer](2.%20Data%20Link%20Layer.md) (Layer 2):
   - Handles error detection and correction, and manages frame synchronisation.
   - Divided into two sub-layers:
     1. **[MAC (Media Access Control)](2.6%20%20Media%20Access%20Control%20\(MAC\)%20Layer.md)** – controls how devices on a network gain access to the medium and permission to transmit data.
     2. **LLC (Logical Link Control)** – provides flow control and error management.
   - Examples: Ethernet, Wi-Fi.

3. **[Network Layer](3.%20Network%20Layer.md) (Layer 3)**:
   - Responsible for logical addressing and routing of packets from source to destination.
   - Protocols: IP (Internet Protocol), ICMP.

4. **[Transport Layer](4.%20Transport%20Layer.md) (Layer 4)**:
   - Ensures reliable data transfer with error correction, flow control, and multiplexing.
   - Protocols: [TCP (Transmission Control Protocol)](4.1%20TCP%20-%20Transmission%20Control%20Protocol.md), [UDP (User Datagram Protocol)](4.2%20UDP%20-%20User%20Datagram%20Protocol.md).

5. **Session Layer (Layer 5)**:
   - Manages and controls the connections between computers, providing sessions, authentication, and reconnection if necessary.
   - Examples: NetBIOS, RPC.

6. **Presentation Layer (Layer 6)**:
   - Translates data between the application layer and the network, including encryption, data formatting, and compression.
   - Example: SSL/TLS for encryption.

7. **[Application Layer](5.%20Application%20Layer.md) (Layer 7)**:
   - The layer that users interact with directly, responsible for services like email, file transfer, and network management.
   - Protocols: HTTP, FTP, SMTP, DNS.

# Network Protocol Functionalities

Dividing network protocol functionalities into mandatory and optional concepts in the OSI model (and similar networking frameworks) helps clarify what functionalities are essential for reliable communication versus those that enhance security, efficiency, or fault tolerance but are not strictly required.

### Mandatory Functionalities

#### 1. **Error Control**:

- Involves mechanisms to detect and correct errors that may occur during data transmission.
- Two main strategies:
  1. **Error Detection**: Using checksums, parity bits, or CRC (Cyclic Redundancy Check) to detect if data has been corrupted.
  2. **Error Correction**: Techniques like ARQ (Automatic Repeat reQuest) request the retransmission of corrupted frames.

#### 2. **Flow Control**:

- Ensures that the sender does not overwhelm the receiver with data by regulating the amount of data sent.
- Methods:
  - **Stop-and-Wait**: Sender sends a packet and waits for acknowledgment before sending the next one.
  - **Sliding Window**: Sender can send multiple frames before needing an acknowledgment but within a certain window size.

#### 3. **Multiplexing / Demultiplexing**:

- **Multiplexing**: Combining multiple signals or data streams into one signal over a shared medium.
  - Example: TCP can handle multiple application layer connections over a single IP connection.
- **Demultiplexing**: The process of separating the combined data streams at the receiver end.
  - Example: Extracting data from a packet to pass to the appropriate application.

---

### Optional Functionalities

#### 1. **Encryption / Decryption**:

- Encryption is the process of converting plain text into a coded form (ciphertext) to protect data from unauthorized access.
- Decryption is the reverse process, converting ciphertext back into its original form.
- Used at various layers (typically the presentation layer) to ensure data security.
- Example: SSL/TLS for secure communication over the internet.

#### 2. **Checkpoint**:

- A checkpoint mechanism allows for periodic saving of the state of a communication session.
- If a failure occurs, the communication can resume from the last checkpoint rather than starting from scratch.
- Used for long sessions or large data transfers to ensure reliability.
