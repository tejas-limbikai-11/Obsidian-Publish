# Media Access Control (MAC)

The [Data Link Layer](2.%20Data%20Link%20Layer.md) in the [OSI model](0.2%20OSI%20Model.md) has two sublayers:

1. **Logical Link Control (LLC) Sublayer**
2. **Media Access Control (MAC) Sublayer**

### Media Access Control (MAC) Layer

The **MAC Layer** is a sublayer of the [Data Link Layer](2.%20Data%20Link%20Layer.md) in the [OSI model](0.2%20OSI%20Model.md), responsible for ensuring reliable data transmission across a shared communication medium. Here’s a breakdown of its key roles and functions in more detail:

#### Key Responsibilities of the MAC Layer

1. **Frame Encapsulation**
   - Takes data packets from upper layers and packages them into frames.
   - Frames are the smallest units of data sent over a network, making them essential for organizing data for transmission.

2. **Addressing**
   - Responsible for determining and managing the unique addresses of devices, both the source (sending device) and the destination (receiving device).
   - Allows the MAC layer to target specific devices within a local network, or groups of devices if sending to multiple destinations.

3. **Multiple Access Resolution**
   - Manages access to the shared communication channel, ensuring that devices don’t send data at the same time and interfere with each other.
   - Uses protocols like **CSMA/CD** (Carrier Sense Multiple Access/Collision Detection) in Ethernet to prevent simultaneous transmissions that can cause collisions.

4. **Collision Detection and Resolution**
   - Detects if two devices try to send data at the same time, causing a "collision" that can corrupt the data.
   - Handles collisions by initiating a retransmission process, where devices wait and retry sending data at a later time to avoid further collisions.

5. **Channel Access Methods**
   - Establishes rules for how devices access the communication channel (physical medium), using methods like **Time Division Multiple Access (TDMA)** or **Code Division Multiple Access (CDMA)**.
   - These methods ensure organized access to the network, especially in high-traffic scenarios.

6. **Error Detection and Correction**
   - Generates **Frame Check Sequences (FCS)** or [checksums](2.4.2%20Checksum.md), which are used to verify the integrity of the transmitted data.
   - If an error is detected in a frame, the MAC layer can request retransmission of the data, reducing the risk of incorrect data transfer.

7. **Abstraction of Physical Layer**
   - Acts as an interface between the physical layer (hardware) and the Logical Link Control (LLC) layer, providing an organized, standardized view of the physical network to upper layers.
   - Simplifies interactions with the physical hardware for higher layers, making network management easier.

### MAC Address

A **MAC Address** (Media Access Control Address) is a unique, hardcoded identifier assigned to the Network Interface Controller (NIC) of a device. It is crucial for device-specific communication within a local network.

MAC addresses are **48 bits** long.

#### Characteristics of MAC Addresses

1. **Uniqueness**
   - Each MAC address is globally unique, ensuring that every device on a network has a distinct identifier.
   - Essential for network security and tracking, since it allows specific devices to be located and addressed on a local network.

2. **Structure**
   - Composed of six groups of two hexadecimal digits, typically displayed in formats like `00:0A:89:5B:F0:11`.
   - The first three octets (first 24 bits) often represent the manufacturer (Organizationally Unique Identifier, OUI), while the remaining three are specific to the device.

3. **Hardwired in NIC**
   - Assigned by the device manufacturer and permanently stored in the NIC, making it difficult to alter without specialized software or hardware.

4. **Use in Network Segments**
   - Primarily used for data transmission within a single network segment, such as Ethernet, Wi-Fi, or Bluetooth.
   - Functions as the device’s "name" in local area networks (LAN), ensuring accurate routing of data within the network segment.

5. **Example of Usage**
   - When data is sent over a network, the MAC address is used as the destination address for routing the data within the local network.
   - Once data reaches the destination NIC with a matching MAC address, it is accepted and processed by that device.

### Why IP Addresses Change, but MAC Addresses Are Fixed

- **IP Address**: An IP address is a logical address assigned to a device on a network for identification and routing purposes. It can change frequently, such as when a device reconnects to a network, moves to a new network, or is assigned a new IP by a DHCP server. IP addresses operate at the [network layer](3.%20Network%20Layer.md) (Layer 3) of the OSI model.

- **MAC Address**: A MAC (Media Access Control) address is a unique, fixed physical address embedded into a device's network interface card (NIC) during manufacturing. It serves as a permanent identifier for the device at the [data link layer](2.%20Data%20Link%20Layer.md) (Layer 2) of the [OSI model](0.2%20OSI%20Model.md). Because it's hard-coded, a device's MAC address remains constant regardless of network changes.

**Relationship**: The fixed MAC address allows devices to retain a unique identifier across networks, while the changeable IP address enables flexible network routing. [ARP](3.4%20ARP%20\(Address%20Resolution%20Protocol\).md) bridges these layers by mapping IP addresses to MAC addresses, allowing devices to communicate effectively within a local network.
