### Introduction to Subnetting

Subnetting is the process of dividing a large network into smaller segments called "subnets." This division allows each subnet to have its own space for communication, making the network easier to manage, more efficient, and more secure. Subnetting helps optimize network performance, enhances security, and simplifies network administration.

### What is a Subnet?

A subnet is essentially a smaller network within a larger network. By creating subnets, we allow devices in a specific subnet to communicate more easily with each other. For example, in a company, each department could have its own subnet, keeping data traffic separate and secure from other departments. Subnets not only help speed up communication but also improve the network's overall organization and security.

### Why is Subnetting Necessary?

Subnetting is essential for several reasons:

- **Efficient Network Organization**: Subnetting organizes networks more efficiently, especially as companies and organizations expand.
- **Traffic Reduction**: Subnetting reduces unnecessary data traffic, enhancing the network's speed and efficiency.
- **Enhanced Security**: By dividing the network, subnetting isolates different segments, which strengthens security and makes monitoring easier.
- **Improved Network Performance**: Each subnet limits the broadcast domain, reducing network congestion and improving performance.

### Different Parts of an IP Address

An IP address has two main parts that help identify a device within a network:

- **Network Portion**: This part of the IP address (typically the first few "octets") identifies the network. Devices on the same network share the same network portion of their IP address, which allows them to communicate within that network.
- **Host Portion**: The remaining section of the IP address identifies the specific device, or "host," within the network. This part makes each device unique within its subnet and helps routers direct data to the correct device.

#### Example of IP Address Structure

A typical IPv4 address has four sections (octets) separated by dots (e.g., `192.168.1.1`). Each octet can range from 0 to 255, which allows for a broad range of unique addresses.

### IP Address Classes in Subnetting

IP addresses are divided into different classes based on the allocation of bits to the network and host portions:

- **[3.1 Classful IP Addressing](3.1%20Classful%20IP%20Addressing.md#Class%20A%20in%20IP%20Addressing|Class%20A)**: Network ID = 8 bits, Host ID = 24 bits.
- **[3.1 Classful IP Addressing](3.1%20Classful%20IP%20Addressing.md#Class%20B%20in%20IP%20Addressing|Class%20B)**: Network ID = 16 bits, Host ID = 16 bits.
- **[3.1 Classful IP Addressing](3.1%20Classful%20IP%20Addressing.md#Class%20C%20in%20IP%20Addressing|Class%20C)**: Network ID = 24 bits, Host ID = 8 bits.

For more information on IP address classes, refer to [Classful IP Addressing](3.1%20Classful%20IP%20Addressing.md).

### How Does Subnetting Work?

Subnetting involves dividing the host portion of an IP address into smaller subnets. Communication between these subnets requires a router, which directs data traffic across different subnets. Each subnet can be identified by a specific "subnet mask," which designates which part of the IP address identifies the network and which part identifies the host.

In **[3.1 Classful IP Addressing](3.1%20Classful%20IP%20Addressing.md#Class%20C%20in%20IP%20Addressing|Class%20C%20IP%20Addresses)**, the first three octets represent the network portion. For instance, let’s consider the example below:

#### Example of Subnetting a [3.1 Classful IP Addressing](3.1%20Classful%20IP%20Addressing.md#Class%20C%20in%20IP%20Addressing|Class%20C%20Address)

**Subnet-1**:

- **Subnet ID**: `193.1.2.0`
- **Range**: `193.1.2.0` to `193.1.2.127`
- **Broadcast ID**: `193.1.2.127`
- **Subnet Mask**: `255.255.255.128`
- **Usable Hosts**: 126 (Out of 128, 2 addresses are reserved for Subnet ID and Broadcast ID)

**Subnet-2**:

- **Subnet ID**: `193.1.2.128`
- **Range**: `193.1.2.128` to `193.1.2.255`
- **Broadcast ID**: `193.1.2.255`
- **Subnet Mask**: `255.255.255.128`
- **Usable Hosts**: 126 (2 addresses are reserved for Subnet ID and Broadcast ID)

By subnetting, we reduce the total number of hosts from 254 (in one large network) to 252 across two subnets.

### Key Notes on Subnetting

1. **Subnet Masks**: The subnet mask defines how the IP address is divided into network and host portions. To find the subnet mask, set the bits for the host ID to 1 and the rest to 0.

2. **Usable Hosts**:
   - We can say that if the total number of subnets in a network increases the total number of usable hosts decreases.
   - Each subnet reduces the total number of usable IP addresses slightly, as each subnet requires an address for the network ID and a broadcast address.

3. **Splitting into Multiple Subnets**:
   - To divide a network into four (2^2) parts you need to choose two bits from the host id part for each subnet i.e, (00, 01, 10, 11).
   - To divide a network into eight (2^3) parts you need to choose three bits from the host id part for each subnet i.e, (000, 001, 010, 011, 100, 101, 110, 111) and so on.

4. **Network Division**:
   - To divide a network into two parts, allocate one bit from the host ID for each subnet. This segmentation allows efficient routing and prevents excessive traffic on a single network.

Subnetting provides an effective way to manage large networks, and the flexibility it introduces makes network management, security, and performance much more manageable.
