### Routers ([Physical Layer](1.%20Physical%20Layer.md), [Data Link Layer](2.%20Data%20Link%20Layer.md), [Network Layer](3.%20Network%20Layer.md))

**1. Can Check MAC Address as Well as IP Address**

- Routers operate at multiple layers of the OSI model (specifically Layers 2 and 3).
- They can inspect both MAC (Media Access Control) addresses at the data link layer and IP (Internet Protocol) addresses at the network layer.
- This capability enables routers to make intelligent forwarding decisions based on the logical addressing scheme of the network.

**2. Forwarding**

- Routers forward data packets based on their destination IP addresses.
- Unlike switches, which operate primarily at Layer 2 and forward frames based on MAC addresses, routers analyze packets at Layer 3, ensuring they reach their intended destination across different networks.

**3. Filtering**

- Routers can filter traffic based on various criteria, such as IP address ranges, protocols, or port numbers.
- This filtering allows routers to implement security measures, control access, and manage network traffic effectively, reducing congestion and enhancing performance.

**4. Routing**

- Routing is the process of determining the optimal path for data packets to travel across networks.
- Routers maintain a **routing table**, which is a database that contains information about the paths to different network destinations.
- The routing table includes entries for various network addresses, the next-hop addresses, and associated metrics (like hop count or path cost), allowing routers to make efficient routing decisions.

**5. Flooding**

- Flooding is a method used by routers to send packets to all possible outgoing links in a network when the destination is unknown.
- This approach can be useful for discovery protocols or when a router cannot find a specific route in its routing table.
- However, excessive flooding can lead to network congestion, so it is typically used selectively.

**6. Collision Domain is Zero**

- Each interface on a router creates a separate collision domain, meaning that devices connected to different router ports do not experience collisions.
- This isolation improves network efficiency and reliability, as multiple devices can communicate simultaneously without interfering with each other.

### Store and Forward Method

- Routers utilize a **store-and-forward** method to handle incoming packets.
- This means that the router receives the entire packet before forwarding it, allowing it to check for errors and evaluate the routing table for the best path to the destination.
- This method enhances data integrity and ensures efficient packet forwarding.
