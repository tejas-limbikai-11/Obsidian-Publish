### Forward Error Correction (FEC)

**Forward Error Correction (FEC)** is a technique for detecting and correcting a limited number of errors in data transmission, eliminating the need for retransmission. FEC is widely used in real-time systems and broadcast applications, where retransmission can be costly or impractical.

#### How FEC Works

- **Redundant Error-Correcting Code**: The sender includes additional error-correcting bits with each data frame, which help the receiver in detecting and correcting errors.
- **Error Detection at Receiver**: The receiver uses the redundant bits to check for errors. If the data is deemed error-free, the receiver applies the error-correcting code to generate the original frame.
- **Removal of Redundant Bits**: Before passing the message to the upper layers, the receiver removes the redundant bits.

#### Advantages and Disadvantages of FEC

- **Advantages**:
  - **No Handshaking Required**: FEC doesn't require acknowledgment from the receiver, making it suitable for broadcasting data from a single source to multiple destinations.
  - **Bandwidth Efficiency**: It saves bandwidth by reducing retransmissions, beneficial in real-time systems where retransmission delays are not feasible.
- **Disadvantages**:
  - **Limit on Correctable Errors**: FEC may not be effective if there are too many errors in the data. In such cases, retransmission may still be necessary.

#### Types of Error Correction Codes in FEC

FEC uses different error-correcting codes to enhance data reliability. The main categories are **block codes** and **convolutional codes**.

- **Block Codes**:
  - The message is divided into fixed-size blocks of bits, with redundant bits added for error correction.
- **Convolutional Codes**:
  - Here, data is processed as a continuous stream, and parity symbols are generated using a Boolean function applied to the data stream.

#### Common Error Correction Codes Used in FEC

1. **[Hamming Codes](2.4.4%20Hamming%20Code.md)**:
   - A type of block code that can detect up to two simultaneous bit errors and correct single-bit errors.

2. **Binary Convolutional Code**:
   - Uses an encoder to process an input bit sequence of arbitrary length, producing an output sequence that includes error-correction information.

3. **Reed-Solomon Codes**:
   - Block codes that correct burst errors in data blocks. Reed-Solomon codes are highly effective in correcting errors in clusters.

4. **Low-Density Parity Check (LDPC) Codes**:
   - LDPC codes use a parity-check matrix with a low density of 1s, making them suitable for large block sizes in noisy channels. They provide reliable error correction in challenging environments.
