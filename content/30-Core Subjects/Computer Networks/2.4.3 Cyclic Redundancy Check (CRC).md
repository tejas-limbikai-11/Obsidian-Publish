## Cyclic Redundancy Check (CRC)

- Unlike the [checksum](2.4.2%20Checksum.md) scheme, which is based on addition, CRC is based on [binary division](https://www.geeksforgeeks.org/binary-division/).
- In CRC, a sequence of redundant bits, called cyclic redundancy check bits, are appended to the end of the data unit so that the resulting data unit becomes exactly divisible by a second, predetermined binary number.
- At the destination, the incoming data unit is divided by the same number. If at this step there is no remainder, the data unit is assumed to be correct and is therefore accepted.
- A remainder indicates that the data unit has been damaged in transit and therefore must be rejected.

The Cyclic Redundancy Check (CRC) is an error-detection technique used in computer networks to ensure data integrity during transmission. Unlike checksum methods that rely on addition, CRC uses binary division to create a unique set of bits, known as CRC bits, that represent the data’s integrity.

#### Working of CRC

1. **Appending CRC Bits:**
   - CRC adds a sequence of redundant bits, known as CRC bits, to the end of a data block.
   - These bits are computed in a way that makes the entire data block (including the CRC bits) exactly divisible by a predefined binary divisor (polynomial).

2. **Binary Division-Based Verification:**
   - The transmitter performs binary division of the data by the binary polynomial (divisor) and appends the remainder as CRC bits to the data.
   - When the receiver gets the data, it divides the entire received data block (including CRC bits) by the same binary polynomial.
   - If the remainder of this division is `0`, the data is assumed to be correct and is accepted.
   - If there is a non-zero remainder, it indicates an error, and the data is rejected.

#### Steps in CRC Calculation

1. **Message Length:**\
   Total bits in the transmitted message is `m + r`, where `m` is the length of the original message, and `r` is the number of redundant CRC bits.

2. **Appending Zeros:**\
   To calculate the CRC bits, `r` zeros (equal to the degree of the polynomial minus 1) are appended to the original message.

3. **Dividing and Replacing Zeros:**\
   The message with appended zeros is divided by the polynomial divisor. The remainder from this division replaces the appended zeros, forming the CRC bits.

4. **Verification at Receiver:**\
   The receiver divides the received data by the same polynomial. If the remainder is zero, the data is accepted; otherwise, it is rejected as erroneous.

#### Error Detection Capabilities

CRC is highly effective in detecting errors, including:

- **All Single-Bit Errors:** Can detect any single-bit error within the data.
- **Odd-Numbered Bit Errors:** Any odd number of bit errors will be detected.
- **Burst Errors:** Capable of detecting burst errors (a series of consecutive bits in error) of a length less than or equal to the degree of the polynomial.

#### Advantages of CRC

1. **High Error Detection Capability:** Detects most common errors, including all single-bit errors and burst errors within the polynomial’s degree.
2. **Minimal Overhead:** CRC only requires a few redundant bits, reducing the need for additional bandwidth.
3. **Efficient Implementation:** Easily implemented in hardware and software for rapid error detection.
4. **Robust Detection for Large Messages:** CRC’s ability to detect patterns of errors makes it suitable for large data transmissions.

### Conclusion

CRC is a robust and efficient error-detection method widely used in computer networks due to its reliability, minimal overhead, and strong ability to detect a wide range of data transmission errors. This makes it an essential tool for ensuring data integrity in networking and communication protocols.
