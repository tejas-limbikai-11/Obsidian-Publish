# Hamming Code (Error Detection and Correction)

Hamming codes are a type of error-correcting code used in digital communication and storage systems to detect and correct errors in transmitted or stored data. Developed by **Richard Hamming**, these codes provide a mechanism to detect and correct single-bit errors and, in certain configurations, detect two-bit errors, making them valuable for reliable data transfer and storage.

#### Key Concepts

1. **Linear Block Codes**: Hamming codes are classified as linear block codes, where blocks of data are encoded with additional bits (parity bits) to create a structure that enables error detection and correction.

2. **Error-Correcting Codes**: Hamming codes are especially useful as they not only detect errors but also enable correction of single-bit errors, improving data integrity.

3. **Parity Bits**: Hamming codes use multiple parity bits that are placed strategically within the data bits. These parity bits are used to maintain either an even or odd parity, depending on the chosen scheme.

4. **Positions of Parity Bits**: Parity bits are placed at positions that are **powers of 2**, such as positions 1, 2, and 4 in a 7-bit Hamming code. Each parity bit oversees specific data bit positions according to binary representation rules.

### 7-Bit Hamming Code (4 Data Bits and 3 Parity Bits)

The 7-bit Hamming code, commonly used in basic applications, includes 4 data bits and 3 parity bits, resulting in a 7-bit code word.

| D4  | D3  | D2  | P3  | D1  | P2  | P1  |
| --- | --- | --- | --- | --- | --- | --- |
| 7   | 6   | 5   | 4   | 3   | 2   | 1   |

Here:

- **D** represents data bits.
- **P** represents parity bits.

### Decoding Rules for Parity Bits

Each parity bit controls specific positions in the code word:

1. **P1 (Position 1)** - (00**1**): Checks bits with binary representations ending in `1` (positions 1, 3, 5, and 7).
2. **P2 (Position 2)** - (0**1**0): Checks bits where the second-to-last binary digit is `1` (positions 2, 3, 6, and 7).
3. **P3 (Position 4)** - (**1**00): Checks bits where the third-to-last binary digit is `1` (positions 4, 5, 6, and 7).

By adjusting the values of parity bits based on the data bits, we achieve either **even** or **odd parity** across each set of positions.

### Example Calculation: Encoding the Bit Sequence 1011 with Even Parity

Q. A bit word 1011 is to be transmitted. Construct the even parity seven-bit hamming code for this data.

Let’s encode the 4-bit data `1011` using even parity for error detection:

1. **Set up the Code Word Format**:

| D4  | D3  | D2  | P3  | D1  | P2  | P1  |
| --- | --- | --- | --- | --- | --- | --- |
| 1   | 0   | 1   |     | 1   |     |     |

2. **Calculate P1**:
   - Positions 1, 3, 5, and 7 are relevant.
   - Bits at these positions are 1, 1, and 1, resulting in an odd count of ones.
   - To make it even, we set `P1 = 1`.

| 1     | 3   | 5   | 7   |
| ----- | --- | --- | --- |
| **1** | 1   | 1   | 1   |

3. **Calculate P2**:
   - Positions 2, 3, 6, and 7 are relevant.
   - Bits at these positions are 1, 0 and 1, giving an even count of ones.
   - To maintain even parity, we set `P2 = 0`.

| 2     | 3   | 6   | 7   |
| ----- | --- | --- | --- |
| **0** | 1   | 0   | 1   |

4. **Calculate P3**:
   - Positions 4, 5, 6, and 7 are relevant.
   - Bits at these positions are 1 and 0, giving an even count of ones.
   - To maintain even parity, we set `P3 = 0`.

| 4     | 5   | 6   | 7   |
| ----- | --- | --- | --- |
| **0** | 1   | 0   | 1   |

5. **Final Code Word**:

|D4|D3|D2|P3|D1|P2|P1|
|---|---|---|---|---|---|---|
|1|0|1|0|1|0|1|

The encoded 7-bit Hamming code for data `1011` with even parity is `1010101`.

### Error Detection and Correction

To detect and correct errors, each parity bit is recalculated at the receiver's end. If any parity calculation fails, the receiver can use the positions associated with failed parity bits to pinpoint the exact bit position in error. By flipping the bit at the identified position, the original data is recovered, achieving single-bit error correction.

### Applications of Hamming Code

- **Data Transmission**: Ensures integrity over unreliable channels.
- **Memory Storage**: Protects data in memory against single-bit errors.

The Hamming code's effectiveness makes it widely adopted for applications that require minimal error detection and correction without significant redundancy.
