# Flow Control Protocols in [ Data Link Layer](2.%20Data%20Link%20Layer.md)

### Stop & Wait **vs** Go-Back-N **vs** Selective repeat

| **[ Stop and Wait](2.2.1%20Stop%20and%20Wait%20Protocol%5C)**                                                                          | **[ Go-Back-N](2.2.2%20Go-Back-N%20Protocol%5C)**                                                   | **[Selective Repeat](2.2.3%20Selective%20Repeat%20Protocol%5C)**            |
| ---------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| Only 1 frame is transmitted at a time.                                                                                       | Multiple frames are transmitted within the window size.                                       | Multiple frames are transmitted within the window size.             |
| **Sender window size** = 1                                                                                                   | **Sender window size** = $(2^k - 1)$<br>(where (k) = number of bits for sequence numbers) | **Sender window size** = $(2^k - 1)$                              |
| **Receiver window size** = 1                                                                                                 | **Receiver window size** = 1                                                                  | **Receiver window size** = $(2^k - 1)$                            |
| **Efficiency** = $\frac{1}{1 + 2x}$  <br>(where $x = \frac{\text{propagation delay}}{\text{transmission time}}$)<br><br> | **Efficiency** = $(2^k - 1) \times \frac{1}{1 + 2x}$<br>                                    | **Efficiency** = $(2^k - 1) \times \frac{1}{1 + 2x}$<br>          |
| Retransmission occurs for a single frame if it is lost or corrupted.                                                         | Retransmission occurs for all frames from the point of error onward.                          | Only the specific lost or corrupted frame is retransmitted.         |
| **Available sequence numbers** = sender window size + receiver window size = 2                                               | **Available sequence numbers** = $(2^k - 1)$                                                | **Available sequence numbers** = $(2^k - 1)$                      |
| Only individual acknowledgments (ACKs) are used.                                                                             | Uses **cumulative acknowledgments** (ACKs) to confirm all frames up to a certain point.       | Uses both **cumulative** and **individual acknowledgments** (ACKs). |
