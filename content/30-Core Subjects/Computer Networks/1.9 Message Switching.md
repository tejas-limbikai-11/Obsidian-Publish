# Message Switching

**Message Switching** is a method of data transmission in computer networks that predates [Packet Switching](1.7%20Packet%20Switching.md). It is designed for systems where complete messages need to be sent from the sender to the receiver in a single, uninterrupted transmission. Here are the main characteristics of message switching:

1. **Predecessor of Packet Switching**:
   - Message switching was widely used before the development of packet switching. Unlike packet switching, which divides data into packets, message switching transmits entire messages in one go, making it simpler but often slower.

2. **Store and Forward Mechanism**:
   - This technique involves storing the entire message at each intermediate node until the next node in the path is ready to receive it. This approach allows for error-checking and message integrity at each node but can introduce delays, especially if a node is busy or the message is large.

3. **Hop-by-Hop Delivery**:
   - Messages are delivered one "hop" at a time, from one intermediate node to the next, until they reach the destination. Each node handles the message independently and forwards it to the next node, ensuring that the network can work around temporary failures or busy paths.

**Advantages**:

- **Reliability**: Messages are fully stored at each node, allowing for retransmission in case of failures.
- **Flexibility**: Nodes can route messages dynamically, adapting to network changes.

**Disadvantages**:

- **Delay**: High latency can result from waiting at intermediate nodes.
- **Storage Requirements**: Large messages require significant storage at each intermediate node.

Message switching paved the way for more efficient methods like packet switching, which splits messages into smaller packets, reducing storage demands and transmission delays in modern networks.
