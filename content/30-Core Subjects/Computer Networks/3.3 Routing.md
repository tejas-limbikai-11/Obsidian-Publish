# Routing

**Routing** is the process of selecting a path for data transfer from a source to a destination across a network. It's a key function in networking that allows data packets to be directed across multiple networks to reach their intended destination. The device performing routing is called a **router**, operating at the [Network Layer](3.%20Network%20Layer.md) (Layer 3) in the [OSI model](0.2%20OSI%20Model.md) and the Internet Layer in the TCP/IP model. Routers use data in the packet header and information from a **routing table** to determine the best path for data transfer. A variety of **routing algorithms** and **protocols** assist routers in this decision-making process, ensuring efficient and reliable data delivery.

#### Key Concepts in Routing

1. **Routing Metrics**: Metrics are standards or measurements like hop count, delay, bandwidth, load, and reliability. Routing algorithms use these metrics to choose the optimal path for packet delivery.
   - **Hop Count**: The number of steps a packet takes across routers from source to destination.
   - **Delay**: Time taken for a router to process, queue, and transmit data.
   - **Bandwidth**: Capacity of the link, measured in bits per second.
   - **Load**: Indicates how busy a network resource or router is.
   - **Reliability**: Measures stability and failure likelihood of a network link.

### Types of Routing

![](https://media.geeksforgeeks.org/wp-content/uploads/20231130224032/Types-of-Routing.png)

1. **Static Routing**
   - **Description**: Also called **non-adaptive routing**, it involves manually setting routes by the network administrator. It provides fine-grained control but can be complex for large networks.
   - **Advantages**:
     - **No Overhead**: Low CPU usage on routers, allowing cheaper hardware.
     - **Bandwidth Efficiency**: Uses no extra bandwidth between routers.
     - **Security**: Routes can be manually restricted to ensure secure data flow.
   - **Disadvantages**:
     - **Complexity in Large Networks**: Requires extensive setup in large networks.
     - **Dependency on Knowledge**: Requires an administrator with good knowledge of network topology.

2. **Dynamic Routing**
   - **Description**: Also known as **adaptive routing**, dynamic routing automatically adapts to changes in network topology, updating routing paths as needed using algorithms like RIP and OSPF.
   - **Advantages**:
     - **Automated Updates**: Routes adjust automatically, making it efficient for networks with frequent changes.
     - **Optimal Path Selection**: Adapts to provide the best route based on network conditions.
   - **Disadvantages**:
     - **Resource Intensive**: Higher CPU and bandwidth usage than static routing.
     - **Security Risks**: Less secure due to dynamic nature and reliance on algorithms.

3. **Default Routing**
   - **Description**: Configures a router to send all packets to a single next-hop device when no specific route is found. It's often used when the network has a single exit point.
   - **Advantages**:
     - **Efficiency in Specific Networks**: Ideal for networks where most traffic heads toward a central device or exit point.
     - **Simplicity**: Simplifies routing when only one default path is needed.
   - **Disadvantages**:
     - **Complexity if Misconfigured**: Without clear configuration, packets may be misrouted, leading to inefficiencies.

#### How Routing Works

Routing directs data packets from the **source node** to the **destination node** by analyzing destination IP addresses. When a data packet is sent, the nearest router receives it, evaluates the routing metrics, and forwards it to the next router along the optimal path. This process continues until the packet reaches its final destination. There are limits to how many hops a packet can take before it’s considered lost, and some protocols use a **Time-to-Live (TTL)** counter to prevent endless looping.

#### Advantages of Routing

- **Scalability**: Routing is scalable, essential for managing data across large networks.
- **Load Balancing**: Helps distribute network traffic, avoiding congested routes to prevent data loss.
- **Network Control**: Provides control over network traffic flow, enhancing security and efficiency.

#### Disadvantages of Routing

- **Static Routing**: Not suitable for large, dynamic networks due to manual configuration needs.
- **Dynamic Routing**: Consumes more resources, which can increase costs and reduce security.
- **Default Routing**: Can become complex if misconfigured, leading to inefficient data transfer.

Routing is integral to modern networking, providing the structure needed to manage and direct data traffic across diverse network configurations. Selecting the correct routing type is crucial, balancing automation with control, to meet specific network needs.
